# 个人知识库 Schema 0.1.0

第一期只描述**本人**。名单封闭：表上的说法只能对齐到本文列出的属性；对不上的标为未对齐，不得临时加类型。只收中文说法，不收英文别名。

变更须升版本。1.3 用「说法 → 属性」对齐，2.2 只按属性名检索。

## 范围

- 主体只有「本人」。紧急联系人不是第二个人，只是本人的三个属性。
- 可重复的经历挂在本人下面：教育经历、工作经历、在校实践、证书。技能是本人的多值属性。
- 不抽取家庭成员、同学、同事为独立实体。
- 抽取不得超出本文属性。没有证据的值留空。

## 实体

| 实体 | 数量 | 说明 |
|------|------|------|
| 本人 | 1 | 当前用户 |
| 教育经历 | 多 | 一条学历或在校就读 |
| 工作经历 | 多 | 一段任职 |
| 在校实践 | 多 | 学生会、实习、实验室等 |
| 证书 | 多 | 语言或专业资格 |

关系只有：本人拥有教育经历、本人拥有工作经历、本人拥有在校实践、本人持有证书、本人具备技能。

| 出生日期 | 日期 | 出生日期、出生年月 |
| 民族 | 文本 | 民族 |
| 政治面貌 | 文本 | 政治面貌 |
| 身份证号 | 文本 | 身份证号、身份证号码 |
| 学号 | 文本 | 学号 |
| 手机号 | 电话 | 手机号、手机号码、移动电话、联系电话、常用联系电话 |
| 邮箱 | 邮箱 | 邮箱、邮件地址、电子邮箱、邮箱地址 |
| 住址 | 文本 | 住址、常住地址、通讯地址 |
| 技能 | 多值文本 | 技能、后端相关技能、技术栈 |

## 教育经历

| 属性 | 类型 | 表上说法 |
|------|------|----------|
| 学校 | 文本 | 学校、院校名称、本科学校、最高学历院校、学校/院系 |
| 学院 | 文本 | 学院、院系 |
| 专业 | 文本 | 专业、本科专业、就读专业、学科方向、专业方向 |
| 学历 | 文本 | 学历、最高学历、学历层次、取得学历 |
| 学位 | 文本 | 学位、学士学位 |
| 毕业年份 | 年份 | 毕业年份、本科毕业年份、毕业时间（年） |
| 在校起止 | 时间段 | 在校起止、在校时间段、起止时间 |

`学校/院系` 写在同一格时，整格对齐到学校，不拆学院。单独出现「学院」或「院系」才写入学院。

## 工作经历

| 属性 | 类型 | 表上说法 |
|------|------|----------|
| 工作单位 | 文本 | 工作单位、任职单位、最近一家公司、当前/近期雇主 |
| 职务 | 文本 | 职务、职务名称、岗位称谓、最近岗位 |
| 工作起止 | 时间段 | 工作起止、供职起止、任职区间、最近一份工作起止年月 |
| 工作职责 | 文本 | 工作职责、主要职责简述 |

## 在校实践

| 属性 | 类型 | 表上说法 |
|------|------|----------|
| 实践单位 | 文本 | 实践单位 |
| 实践角色 | 文本 | 实践角色、承担角色、在校职务或实践 |
| 在校起止 | 时间段 | 在校起止、时段 |
| 实践说明 | 文本 | 实践说明、内容摘要、补充说明 |

## 证书

| 属性 | 类型 | 表上说法 |
|------|------|----------|
| 证书名称 | 文本 | 证书名称、专业证书（可多项）、名称 |
| 证书类别 | 文本 | 证书类别、类别 |
| 证书说明 | 文本 | 证书说明、说明 |

证书表里的「名称」「类别」「说明」只在证书清单中使用。别的表上单独的「说明」不对齐到证书说明。

## 不对齐

这些说法太宽，或第一期不收，标为未对齐：

- 联络、编号联络
- 备注
- 血型，以及本文未列出的任何新栏目

## 类型

| 类型 | 写法 |
|------|------|
| 文本 | 原文字，去掉首尾空白 |
| 电话 | 仅数字，保留前导区号中的数字 |
| 邮箱 | 原文字 |
| 日期 | `YYYY-MM-DD`；只有年月时用 `YYYY-MM` |
| 年份 | `YYYY` |
| 时间段 | `YYYY-MM 至 YYYY-MM` |
| 多值文本 | 多项分开存放，不拼成一句 |

无法规范成上表的值留空，不猜测。
