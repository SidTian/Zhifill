1. **2.1** 发布 Schema 初稿，1.1/1.3/2.2 已对齐。
2. **1.1** 多源历史资料可进入统一表示；**2.1** 建图谱后问答能答本人事实；**新上传文档后出现新事实**。
3. 更新/删除知识后答案一致（无陈旧主事实）。
4. **1.2** 至少 Word 任务文件可解析结构与填写位置；**1.3** 产出 TaskSpec。
5. **2.2** 基于 TaskSpec + 图谱给出建议填写（含来源/置信度策略）；无证据不瞎填。
6. **统筹** 前端可预览修改；Word（及已支持的 Excel/PDF）**回填下载**正确。
7. 用户确认值 **不回写** 图谱。
8. 本地或 Compose 可启动 Demo。
